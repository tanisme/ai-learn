# 《AI Agent 工程师面试专项训练课程》



2026 年面试能力体系

理论 + 代码 + 项目 + 部署



这套课程按照企业级 AI Agent 工程师的实际岗位要求设计，不以单纯学习框架为目标，而是以最终能够独立完成企业级 Agent 系统开发，并通过中高级 AI Agent 工程师技术面试为目标。

我会采用循序渐进的方式：

1. 先明确每章、每节需要掌握的知识点。
2. 讲解基本原理，再深入底层机制和实现细节。
3. 每个重要知识点都配有完整、可运行的 Python 代码。
4. 每章配套面试题、参考答案和实战练习。
5. 最后将所学技术整合成多个完整项目。
6. 完成 Docker 部署、Linux 部署、测试、监控和性能优化。

课程不会只展示伪代码，也不会只介绍 API。 对于核心模块，会给出完整目录结构、每个文件的具体实现、模块间调用关系、异常处理和详细注释。

## 三、每一章具体采用什么教学方式？

为了保证学习深度，所有章节采用统一结构。

以第 24 章 LangGraph 为例：

第 24 章：LangGraph 深入

1. 24.1 LangGraph 架构原理

   为什么需要 Graph？与 Chain、传统 Agent 有什么区别？
2. 24.2 State 状态管理

   TypedDict、Annotated、Reducer、状态更新机制。
3. 24.3 Node 节点机制

   节点执行、输入输出、异步节点、异常处理。
4. 24.4 Edge 与条件路由

   普通边、条件边、动态路由。
5. 24.5 Checkpoint

   状态快照、持久化、恢复执行。
6. 24.6 Interrupt 与 Human-in-the-Loop

   人工审批、暂停、恢复、Command。
7. 24.7 Subgraph

   子图封装、状态共享、多 Agent 组织。
8. 24.8 并发与异常恢复

   节点并行、重试、超时、执行失败。
9. 24.9 完整实战

   开发一个带持久化、人工审批和恢复能力的 Agent。
10. 24.10 面试专项

    原理题、源码分析题、代码题、架构设计题。

每一节都按照：

知识点 → 原理 → 内部机制 → 代码实现 → 执行过程 → 常见问题 → 面试题

## 五、课程开发规范

为了避免后续学习过程中代码不完整、版本不一致，我建议统一以下规范。

| 项目     | 规范                     |
| ------ | ---------------------- |
| Python | Python 3.11+           |
| 后端     | FastAPI                |
| 数据库    | PostgreSQL             |
| 缓存     | Redis                  |
| ORM    | SQLAlchemy 2.x         |
| Agent  | LangChain、LangGraph    |
| 向量数据库  | Qdrant                 |
| 模型接口   | OpenAI 兼容 API、DeepSeek |
| 容器     | Docker、Docker Compose  |
| 测试     | pytest                 |
| 部署     | Linux + Docker + Nginx |

另外，所有项目遵循以下原则：

1. 每个项目都有完整的目录结构。
2. 每个 `.py` 文件都提供完整代码。
3. 代码不使用伪代码代替关键逻辑。
4. 说明模块之间的依赖关系和调用流程。
5. 包含异常处理、日志、测试和配置管理。
6. 固定依赖版本，避免前后章节 API 不一致。
7. Windows 本地开发，Linux Docker 环境部署。
8. 每个项目完成后提供启动、测试和部署步骤。

考虑到你之前已经学习过 LangChain、LangGraph、FastAPI、SSE，并且开发过企业级 Agent 平台，我们不会把这些内容简单重复一遍，而是进一步深入底层原理、工程实现和生产环境问题。尤其会加强 Checkpoint、任务恢复、异步执行和跨模块架构设计。
